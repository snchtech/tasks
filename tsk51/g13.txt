Чудово 👍 VS Code — це якраз найзручніший варіант для такого масового рефакторингу.

Нижче даю **чіткий, безпечний алгоритм**, щоб ти нічого зайвого не зламала.

---

# ✅ Що потрібно зробити

Тобі треба:

```
tsk.nameobj@tott_10   →   tsk.nameobj
```

Але НЕ чіпати:

```
bsk.nameobj@tott_10
other.name@tott_10
```

---

# 🔐 КРОК 1 — Обов'язково зроби backup

1. Export APEX application
2. Збережи окрему копію файлу

   ```
   app_backup.sql
   ```

---

# 🚀 КРОК 2 — Відкрий файл у VS Code

1. Ctrl + H  (Replace)
2. Увімкни режим **Regex** (іконка `.*`)

---

# 🎯 КРОК 3 — Встав правильний REGEX

## 🔎 Find:

```regex
\btsk\.([A-Za-z0-9_]+)@tott_10\b
```

## 🔁 Replace:

```
tsk.$1
```

---

# 🧠 Що це означає

| Частина           | Що робить              |
| ----------------- | ---------------------- |
| `\b`              | межа слова             |
| `tsk\.`           | тільки схема tsk       |
| `([A-Za-z0-9_]+)` | будь-який об'єкт       |
| `@tott_10`        | саме цей dblink        |
| `$1`              | повертає назву об'єкта |

---

# 🔎 КРОК 4 — Спочатку перевір через "Find All"

Натисни **Find All**
Переконайся, що знаходяться тільки `tsk.*@tott_10`

Якщо бачиш щось зайве — зупинись.

---

# 🔄 КРОК 5 — Replace All

Після перевірки — Replace All.

---

# 🧪 КРОК 6 — Додаткова перевірка

Після заміни зроби пошук:

```
tsk.@tott_10
```

або

```
@tott_10
```

Щоб переконатися, що:

* у tsk більше немає dblink
* у bsk та інших він залишився

---

# 💡 Важливий момент

Іноді в APEX export буває:

```
"TSK"."TABLE_NAME"@tott_10
```

Якщо таке є — додатковий regex:

### 🔎 Find:

```regex
"TSK"\."([A-Za-z0-9_]+)"@tott_10
```

### 🔁 Replace:

```
"TSK"."$1"
```

---

# 🏆 Якщо хочеш зробити максимально акуратно

Можеш зробити replace тільки в SQL блоках, але у 99% випадків достатньо цього regex.

---

# ⚠ Після імпорту

Перевір:

* всі views
* dynamic actions з PL/SQL
* processes
* packages якщо є

---

# 📌 Якщо раптом буде помилка після імпорту

Найчастіша причина:

* локальна схема не має прав
* об'єкт існує в іншому schema

Тоді треба:

```
GRANT SELECT ON tsk.table_name TO parsing_schema;
```

---

Якщо хочеш — можу дати ще більш "розумний" regex, який не зачепить рядки всередині JSON або HTML.
